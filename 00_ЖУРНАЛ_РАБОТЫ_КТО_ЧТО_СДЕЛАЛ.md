## С чего продолжать

Порядок — по важности. Взяли задачу — допишите `← Имя, дата`.

3. Заявка в bePaid на эквайринг с регулярными списаниями по сохранённой карте.
4. Интервью с 10–15 будущими пользователями: сколько готовы откладывать, что пугает, нужны ли акции.

**Техника:**
5. Арендовать тестовый сервер в РБ (2 vCPU / 4 ГБ / 40–60 ГБ, Ubuntu 24.04), домен, развернуть по `deploy/` с паролем (`Caddyfile.staging`).
6. Telegram-бот (токен от @BotFather) и почта (SMTP) — для уведомлений и подтверждения почты.
7. После получения API оператора — модуль `WhitebirdBroker` в `internal/engine` (оценка 3–4 недели).
8. Toncoin (TON) с 30.06.2026 не торгуется на Binance (статус BREAK), а Bybit его не поддерживает: решить — убрать TON
   из стратегии «Максимум» или брать цену из другого источника.
9. Если акции США остаются — лицензированный источник котировок вместо Yahoo Finance.

## Как работать вдвоём через GitHub

```bash
git clone https://github.com/alxtchshv/autoinvest-by.git   # один раз
cd autoinvest-by
make test-stand                                            # Windows: test_stand.bat
```

Каждый раз:
```bash
git pull                     # забрать изменения напарника
# ...работаем...
git add -A && git commit -m "Коротко, что сделано"
git push
```

- Крупную или рискованную задачу делайте в отдельной ветке (`git switch -c feature/название`) и открывайте Pull Request —
  второй посмотрит перед слиянием.
- Если `git pull` пишет о конфликте — не удаляйте чужое, откройте файл, оставьте обе правки и закоммитьте.
- Не коммитьте `.env`, базы `data/` и `data-test/` — они уже в `.gitignore`.
