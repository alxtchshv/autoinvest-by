```
  (Крипта: цены, объемы,       (Живые тикеры, свечи,          (Акции: S&P 500, AAPL,
   капитализация, история)      стаканы, WebSockets)           NVDA, котировки в USD)
       │                              │                              │
       └──────────────────────────────┼──────────────────────────────┘
                                      │
                                      ▼
                        MARKET DATA SERVICE (Go Engine)
                                      │
                         ┌────────────┴────────────┐
                         ▼                         ▼
                 Кеш в оперативной          API Нацбанка РБ (НБРБ)
                  памяти (In-Memory)        (Официальный курс USD/BYN)
                         │                         │
                         └────────────┬────────────┘
                                      │
                                      ▼
                        ИТОГОВЫЙ СЕРВЕРНЫЙ КЭШ:
                        - Цена актива в USD и BYN
                        - Изменение за 24ч / 7д / 30д / 1г
                        - Массив свечей для графиков
```

### 2.1. Конкретные эндпоинты бесплатных провайдеров:
1. **Криптовалюты (CoinGecko API v3):**
   - URL: `https://api.coingecko.com/api/v3/coins/markets?vs_currency=usd&ids=bitcoin,ethereum,tether,solana,the-open-network`
   - Отдает: текущую цену, `price_change_percentage_24h`, капитализацию, `high_24h`, `low_24h`.
2. **Акции США и индексы (Finnhub Public API / Yahoo Finance API):**
   - URL (Quote): `https://finnhub.io/api/v1/quote?symbol=AAPL&token=PUBLIC_KEY`
   - URL (Candles): `https://query1.finance.yahoo.com/v8/finance/chart/SPY?interval=1d&range=1y`
   - Отдает: дневные свечи (Open, High, Low, Close, Volume) для построения исторических графиков.
3. **Конвертация в белорусские рубли (Официальный API НБРБ):**
   - URL: `https://api.nbrb.by/exrates/rates/USD?parammode=2`
   - Отдает: актуальный курс белорусского рубля к доллару США на сегодня, что позволяет мгновенно показывать любой актив в BYN.

### 2.2. Стратегия кеширования (Rate-Limit Protection):
* Бэкенд на Go опрашивает внешние API фоновым воркером **раз в 60 секунд** и сохраняет результат в потокобезопасную память сервера.
* Фронтенд (клиенты) получают котировки с нашего собственного сервера мгновенно (за 5–10 мс) без риска превысить лимиты сторонних API.

## 3. СИСТЕМА ОЦЕНКИ И СКОРИНГА РИСКОВ (RISK ENGINE)

Чтобы защитить неопытных пользователей от неоправданных потерь и обучать их финансовой грамотности, каждый актив и каждый собранный портфель получают **индекс риска по 5-балльной шкале («Светофор»)**:

```
[Уровень 1] 🟢 МИНИМАЛЬНЫЙ    | USDT, Корпоративные облигации (Колебания < 3%)
[Уровень 2] 🟢 НИЗКИЙ          | Золото (PAXG), Надежные фонды (Колебания 3–10%)
[Уровень 3] 🟡 УМЕРЕННЫЙ       | S&P 500 ETF, Apple, Microsoft (Колебания 10–20%)
[Уровень 4] 🟠 ПОВЫШЕННЫЙ      | Bitcoin, Ethereum (Колебания 30–60%)
[Уровень 5] 🔴 ВЫСОКИЙ         | Solana, TON, Nvidia, Tesla (Колебания > 60%)
```

### 3.1. Математические метрики, рассчитываемые сервером:
1. **Историческая волатильность ($\sigma$, Volatility):**
   - Стандартное отклонение суточных доходностей актива за последние 90 и 365 дней. Показывает, насколько сильно «трясет» цену.
2. **Максимальная просадка (Max Drawdown, MDD):**
   $$\text{MDD} = \frac{\text{Trough Value} - \text{Peak Value}}{\text{Peak Value}} \times 100\%$$
   - Показывает худший сценарий в истории: если бы пользователь купил на самом пике, сколько процентов он бы временно потерял на дне кризиса (например, для S&P 500 это ~ -20%, а для Bitcoin ~ -70%).
   - Отображается в карточке актива: *«Историческая глубина падения: не более 19.5% за 3 года»*.
3. **Индекс страха и жадности (Crypto Fear & Greed Index):**
   - Значение от 0 (экстремальный страх) до 100 (экстремальная жадность). 
   - Помогает новичку понять: когда на рынке «страх» — это лучшее время для регулярных покупок по DCA по низкой цене!

## 5. ПРОДВИНУТЫЙ КОНСТРУКТОР ПОРТФЕЛЯ (CUSTOM SMART DCA)

Пользователь не ограничен фиксированными тарифами. Он может собрать **свой уникальный финансовый коктейль**:

### 5.1. Интерактивный Drag-and-Drop билдер:
* Пользователь нажимает `[+ Добавить актив]`, выбирает активы из каталога:
  * Например: `SPY (S&P 500)` + `USDT` + `Bitcoin` + `Apple`.
* Для каждого актива появляется интерактивный ползунок процентов:
  * S&P 500: `40%`
  * USDT: `30%`
  * Bitcoin: `20%`
  * Apple: `10%`
* **Автовалидация:** Система не дает сохранить план, пока сумма долей строго не равна **100%**.
* **Живой пересчет совокупного риска:**
  $$\text{Портфельный риск} = \sum (\text{Доля}_i \times \text{Риск}_i)$$
  Система показывает бейдж: *«Совокупный риск вашего портфеля: 2.6 / 5 (Умеренно-консервативный)»*.

### 5.2. Умные триггеры автопокупки (Smart DCA Triggers):
1. **Календарный триггер (Классический DCA):**
   - Списание фиксированной суммы (например, 20 BYN) каждую неделю / в день зарплаты.
2. **Триггер «Buy the Dip» (Докупка на распродажах):**
   - Пользователь включает галочку: *«Если актив из моего портфеля падает более чем на 5% за сутки — автоматически докупить на 10 BYN»*.
   - Это позволяет выкупать локальные просадки рынка по минимальной цене в автоматическом режиме.
3. **Автоматическая ребалансировка (Rebalancing):**
   - Если за счет роста Биткоина его доля в портфеле выросла с 20% до 35%, система при следующих автопокупках временно направляет 100% новых денег в отстающие активы (S&P 500 и USDT), возвращая баланс к эталону.

## 7. РЕЗЮМЕ ДЛЯ КОМАНДЫ РАЗРАБОТКИ

1. Мы уходим от примитивной модели «пара кнопок» к **полноценной мультиактивной финтех-платформе** (Крипта + Мировые акции + Облигации РБ).
2. Белорусское законодательство (Декрет № 8) позволяет легально интегрировать токенизированные акции через резидентов ПВТ.
3. Сервер на **Go** занимается только тем, в чем он лучший в мире: безопасностью, деньгами, расчетами и интеграциями.
4. Клиентский интерфейс проектируется для максимальной наглядности: со светофором рисков, живыми графиками и умными триггерами докупки на просадках.
