## Быстрый запуск

**Windows** — дважды кликните `run.bat`: он соберёт `bin\autoinvest.exe` (если установлен Go), запустит сервер и откроет `http://localhost:8080`.
* `create_demo.bat` — демо-аккаунт `demo@autoinvest.by` / `demo12345`;
* `create_admin.bat` — администратор (спросит почту и пароль).

**macOS / Linux**
```bash
make run                                  # сервер на http://localhost:8080 (или ./scripts/run.sh)
make demo                                 # демо-аккаунт demo@autoinvest.by / demo12345
make admin EMAIL=you@mail.by PASS=parol123
make test                                 # все тесты Go
make build                                # фронтенд (если есть Node.js) + bin/autoinvest
```

Нужен Go 1.24+. Node.js 20+ — только если меняете интерфейс в `web/app` (готовая сборка лежит в `web/dist` и встраивается в бинарник).
Настройки — в `.env` (скопируйте `.env.example`). Комментарии после значения (`ADDR=:8080  # пояснение`) поддерживаются.

```bash

cp deploy/Caddyfile.staging deploy/Caddyfile               # тестовый контур: пароль и noindex
```

## Режимы работы — важно перед показом людям

| Что | Сейчас | Что нужно для реальных денег |
| --- | --- | --- |
| Платежи | `PAYMENTS=sandbox`: тестовые карты, деньги не списываются | договор с bePaid, `PAYMENTS=bepaid`, `BEPAID_TEST=false` |
| Покупка активов | `BROKER=paper`: учёт по реальным биржевым ценам, сделки не исполняются | договор и API оператора-резидента ПВТ (Whitebird и т.п.), `BROKER=whitebird` |
| Котировки | Binance → Bybit → CoinGecko, акции — Yahoo Finance, курс — НБРБ | для коммерции заменить Yahoo на лицензированный источник (Finnhub, Polygon) |

Боевые списания при учебном исполнении запрещены в коде: сервер не стартует с `BEPAID_TEST=false` и `BROKER=paper`.

**Курс НБРБ.** Если api.nbrb.by недоступен, сервис **не подставляет выдуманный курс**: показывает последний настоящий курс из базы с пометкой «устарел» и не проводит покупки, пока курс старше суток.

## Перед запуском (чек-лист)
1. Юрист проверяет тексты `/legal/offer`, `/legal/privacy`, `/legal/risks`, `/legal/tax` (`web/app/src/pages/public/Legal.tsx`) и вписывает реквизиты оператора. При изменении текста повысьте `LegalVersion` в `internal/api/h_extra.go`: согласия хранятся с номером редакции.
2. Регистрация в реестре операторов персональных данных и локализация серверов (Закон № 99-З), если требуется.
3. Договоры с bePaid и оператором-резидентом ПВТ, ключи в `.env`.
4. Токены компаний РБ (`BYCORP_USD`, `BYCORP_BYN`) — учебная модель с условной ставкой. Замените на реальные выпуски площадки-партнёра.

## О проекте
**AutoInvest BY** — финтех-сервис для регулярного автоинвестирования небольших сумм (от 5–10 BYN) по стратегии усреднения долларовой стоимости (Dollar Cost Averaging, DCA) в Республике Беларусь.
Сервис работает по **non-custodial модели**: выступает технологическим фасадом и планировщиком, направляя транзакции через открытые API лицензированных белорусских партнеров (ЗАО «Уайт Бёрд» и платежные агрегаторы).
