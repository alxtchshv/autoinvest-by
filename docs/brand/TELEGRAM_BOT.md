# Оформление Telegram-бота @AutoInvestAgent

Токен — только в `.env` (`TELEGRAM_BOT_TOKEN`), в репозиторий не коммитить. Если токен попал в чужие руки — @BotFather → `/revoke`.

## Что ставится автоматически при запуске сервиса
- Описание в пустом чате («Что умеет бот») и короткое «о боте» — `internal/telegram/bot.go` (`botDescription`, `botAbout`).
- Список команд: /menu, /balance, /plans, /history, /support, /phone, /stop.

## Что сделать вручную в @BotFather (Bot API не умеет)
1. Аватарка: `/setuserpic` → выбрать бота → отправить `telegram-avatar.png` из этой папки (640×640, Telegram обрежет в круг).
2. Имя бота уже «AutoInvest». При желании: `/setname`.
3. Группа поддержки:
   - @BotFather → `/setprivacy` → выбрать бота → **Disable** (иначе бот не видит ответы сотрудников в группе);
   - создать группу, добавить в неё бота (если privacy меняли после добавления — удалить и добавить бота заново);
   - написать в группе `/chatid` — бот ответит ID группы (вида `-100…`);
   - записать его в `.env` как `TELEGRAM_SUPPORT_CHAT_ID=…` и перезапустить сервис.
   Отвечать клиентам: свайп «Ответить» на сообщение «Новое обращение #N». Отвечать могут только сотрудники — аккаунт AutoInvest
   с ролью admin/support, к которому в Профиль → Уведомления подключён этот Telegram.

## Второй разработчик
Владелец у бота один (передать можно в @BotFather → Bot Settings → Transfer Ownership). Один токен нельзя одновременно
использовать с двух компьютеров: Telegram отдаёт сообщения только одному процессу (ошибка «Conflict: terminated by other
getUpdates request»). Поэтому каждый разработчик создаёт себе **свой тестовый бот** в @BotFather и пишет его токен в свой `.env`;
токен @AutoInvestAgent живёт только на сервере.
