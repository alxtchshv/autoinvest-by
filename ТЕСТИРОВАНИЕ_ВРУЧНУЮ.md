# Тестовый стенд: как потыкать AutoInvest руками

Стенд — то же приложение, но **без настоящих денег**: карты только тестовые, покупки учебные по **реальным** ценам
бирж и курсу НБРБ. У стенда своя база `data-test/`, рабочую `data/` он не трогает.

## Запуск

| Система | Команда |
| :--- | :--- |
| macOS / Linux | `make test-stand` или `./scripts/test-stand.sh` |
| Windows | двойной клик по `test_stand.bat` |
| Начать с чистого листа | `make test-stand-reset` / `test_stand.bat reset` |
| Остановить стенд, запущенный в фоне | `make test-stand-stop` |

Откройте **http://localhost:8090** (у стенда свой порт, чтобы не мешать обычному запуску на 8080). Остановка — `Ctrl+C` в окне терминала или `make test-stand-stop`.
Если стенд уже запущен, повторная команда не упадёт, а напишет «Стенд уже запущен» — просто откройте адрес в браузере.

## Аккаунты (только для стенда)

| Кто | Логин | Пароль |
| :--- | :--- | :--- |
| Пользователь с двумя копилками | `demo@autoinvest.by` | `demo12345` |
| Администратор (`/admin`) | `admin@autoinvest.test` | `admin12345` |

Можно и зарегистрироваться самому: письма не уходят, ссылка подтверждения почты печатается в окне сервера.

## Тестовые карты

| Номер | Что происходит |
| :--- | :--- |
| `4200 0000 0000 0000` | Visa, всё проходит (на стенде показывается как Беларусбанк) |
| `5555 5555 5555 4444` | Mastercard, всё проходит (как Приорбанк) |
| `9112 0000 0000 0006` | Белкарт, всё проходит (как Белагропромбанк) |
| `4005 5500 0000 0019` | Карта привязывается, но **списания отклоняются** («недостаточно средств»; как Альфа-Банк) |
| `4000 0000 0000 0002` | Банк **отклоняет привязку** |

Срок действия — любой в будущем (например `12/30`), CVC — любые 3 цифры, имя — латиницей.
Настоящий номер карты стенд не примет. Банки у тестовых карт условные — чтобы было видно, как карта оформляется в цвета банка;
в бою название банка присылает bePaid, а если не прислал — сервис смотрит справочник по первым 6 цифрам (BIN).

## Сценарии (пройдите по порядку)

### 1. Новый пользователь
1. «Открыть копилку» → регистрация. Обе галочки обязательны: оферта с рисками и согласие на обработку данных.
2. Сразу открывается анкета из 4 вопросов. Ответьте — получите план и «Создать эту копилку в 1 клик».
3. Если карты нет, откроется страница карт: «Привязать карту» → тестовая карта `4200…`.
4. На карте видна маска `4200 00•• •••• 0000`: полный номер не хранится.

### 1а. Копилка под цель
1. «Новая копилка» → название, «Сколько хочу накопить» (например, 3 000) и «К какой дате» → «Через год».
2. Выберите план. На шаге «Сколько и когда» сервис сам предложит сумму и частоту, чтобы успеть к сроку; их можно поменять.

### 2. Купить
1. «Копилки» → откройте копилку → **«Включить»**, если она на паузе (созданная без карты копилка ждёт карту).
2. **«Пополнить»** → сумма → покупка проходит сразу по текущей цене. В копилке появятся активы, на главной — стоимость.
3. Меню **«⋯» → «Тест: пополнить по расписанию сейчас»** — запускает плановое пополнение, не дожидаясь пятницы. Этот пункт есть только на стенде.
4. «Операции» → откройте операцию → чек с курсом НБРБ, ценой и комиссией. «Сохранить в PDF».

### 3. Отказ банка
1. Привяжите карту `4005 5500 0000 0019` и сделайте её основной («Карты» → «Сделать основной»).
2. Пополните копилку → отказ «недостаточно средств», деньги «не списаны», приходит уведомление.
3. После трёх отказов подряд по расписанию копилка встаёт на паузу.

### 4. Вывод и закрытие
1. В копилке «Вывести» → часть суммы. Сервис попросит пароль, продаст активы по текущей цене и проведёт тестовую выплату на карту; в «Операциях» появится вывод с чеком.
2. «Закрыть копилку» → всё продаётся.

### 5. Pro и акции
1. «Профиль» → «Тариф» → оплатить Pro тестовой картой.
2. «Рынок» → внизу «Токенизированные акции США» и «Токены белорусских компаний».
3. «Новая копилка» → «Свой состав» → добавьте SPY или NVDA.
4. Токены компаний Беларуси добавляются так же, через «Свой состав».

### 6. Безопасность и личный кабинет
- «Профиль» → «Безопасность»: 2FA (Google Authenticator / Яндекс Ключ), сеансы (любой чужой можно завершить отдельно), история входов, согласия, «Скачать мои данные».
- «Профиль» → «Пароль»: смена пароля. «Профиль» → «Журнал действий»: выгрузка файлом за период.
- «Профиль» → «Верификация», два пути:
  - **Через банк (МСИ)** — откроется тестовая страница МСИ: любой корректный идентификационный номер
    (например `3010195A001PB7`) и любой код из 6 цифр. Личность подтверждается сразу.
  - **По паспорту и селфи** — загрузите любые два фото; через ~4 секунды тестовая проверка одобрит их сама
    (как вебхук Sumsub в бою). Страница обновится без перезагрузки.
  - Чтобы пройти заново на стенде: `make test-stand-reset` или удалить строку пользователя из таблицы `kyc`.

### 6а. Регистрация, вход, Telegram и вторая защита (тестовые режимы)
- **Регистрация:** имя, почта, пароль → «Получить код на почту». Почта на стенде не настроена, поэтому код показан на экране;
  после ввода кода создаётся аккаунт (почта сразу подтверждена).
- **Google:** «Продолжить с Google» → тестовая страница. Почта существующего пользователя (`demo@autoinvest.by`) — войдёт
  в него; новая — создаст аккаунт без пароля (пароль можно задать: Безопасность → «Почта и пароль» → «Задать»).
- **Telegram:** Профиль → Уведомления → «Подключить Telegram» → откроется тестовый чат с ботом.
- **Телефон:** Безопасность → «Телефон и код в Telegram» → «Подтвердить» → в чате кнопка «Поделиться номером»
  (на стенде спросит номер). Затем «Войти» → «Код в Telegram»: код придёт в чат бота (на стенде — ещё и на экран).
  Можно и «почта или телефон» + пароль.
- **Вторая защита:** Безопасность → «Код из Google Authenticator» (QR) и/или «Face ID, Touch ID или отпечаток»
  (работает в Safari/Chrome на устройстве с датчиком или с Windows Hello). Потом при входе по паролю или коду попросит
  код или касание; вывод денег, закрытие копилки, смена пароля и удаление аккаунта — тоже. Вход через Google второй шаг не просит.
- **Вход одним касанием:** после добавления Face ID на странице входа появится «Войти по Face ID или отпечатку» — без почты и кода.
  Проверять в Safari или Chrome на Mac с Touch ID / iPhone (во встроенном браузере Claude датчика нет).

### 7. Выписки
«Операции» → выберите период → «Таблица для Excel» или «Выписка для печати и PDF».

### 8. Админка (`admin@autoinvest.test`)
Обзор и блок «Для партнёров и инвесторов» (воронка, удержание, активы), пользователи, верификация, обращения в поддержку, заявки и ручные выплаты, состояние источников котировок.

## Если что-то не так
- **Цены не грузятся:** нужен интернет (Binance/Bybit/CoinGecko/Yahoo/НБРБ). Без интернета запускайте с `MARKET=fixture`: цены будут демонстрационные.
- **«Котировки недоступны» при покупке:** курс НБРБ ещё не загрузился или старше суток. Подождите минуту после старта.
- **«Порт занят другой программой»:** `ADDR=:8091 PUBLIC_URL=http://localhost:8091 ./scripts/test-stand.sh` (в Windows поменяйте `ADDR` и `PUBLIC_URL` в `test_stand.bat`).
